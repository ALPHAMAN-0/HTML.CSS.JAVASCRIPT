# 🌐 Network Engineer Learning Roadmap

A comprehensive, interactive web-based learning roadmap designed to guide junior network engineers through their journey from fundamentals to advanced expertise.

## 📋 Overview

This interactive roadmap provides a structured learning path covering all essential topics a network engineer needs to master, from basic networking concepts to advanced automation and cloud technologies.

## ✨ Features

- **Interactive Progress Tracking**: Check off topics as you complete them
- **Progress Persistence**: Your progress is automatically saved in browser localStorage
- **Visual Progress Bar**: See your overall completion percentage at a glance
- **Expandable Sections**: Click phase headers to expand/collapse content
- **Celebration Effects**: Special animation when you complete all topics!
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Print-Friendly**: Optimized for printing as a reference guide

## 🎯 Learning Phases

1. **Phase 1: Networking Fundamentals (0-6 months)**
   - OSI Model & TCP/IP Stack
   - IP Addressing & Subnetting
   - Network Devices
   - Ethernet & LAN Technologies
   - Basic Network Troubleshooting

2. **Phase 2: Routing & Switching (6-12 months)**
   - Routing Protocols (RIP, EIGRP, OSPF, BGP)
   - Spanning Tree Protocol
   - Advanced VLAN Configuration
   - WAN Technologies
   - High Availability & Redundancy

3. **Phase 3: Network Security (12-18 months)**
   - Firewall Technologies
   - VPN Technologies
   - Network Access Control
   - Network Monitoring & IDS/IPS
   - Security Best Practices

4. **Phase 4: Wireless & Modern Tech (18-24 months)**
   - Wireless Networking (WiFi 6/6E)
   - Cloud Networking (AWS, Azure, GCP)
   - Software-Defined Networking (SDN)
   - Network Function Virtualization (NFV)
   - 5G & IoT Networking

5. **Phase 5: Network Automation (24-30 months)**
   - Python for Network Engineers
   - APIs & REST
   - Infrastructure as Code (Ansible, Terraform)
   - Version Control & CI/CD
   - Network Telemetry & Observability

6. **Phase 6: Advanced Topics & Specialization (30+ months)**
   - Advanced Certifications (CCIE, JNCIE)
   - Network Architecture Design
   - Troubleshooting Mastery
   - Performance Optimization
   - Leadership & Soft Skills

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. Start with Phase 1 and work through each topic systematically
3. Check off topics as you complete them
4. Track your progress with the progress bar at the top

## 💾 Progress Management

- **Auto-Save**: Your progress is automatically saved to your browser's localStorage
- **Export**: Press `Ctrl+E` (or `Cmd+E` on Mac) to export your progress
- **Reset**: Press `Ctrl+R` (or `Cmd+R` on Mac) to reset all progress

- **Professional**: CCIE, JNCIE, CISSP
